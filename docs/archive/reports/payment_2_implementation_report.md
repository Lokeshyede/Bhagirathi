# PAYMENT-2: Tenant Payment Module — Implementation Report

## Summary

PAYMENT-2 (Tenant Payment Module) is fully implemented, verified with 7 automated integration tests (7/7 passed), and fully integrated with PAYMENT-1 (Billing Foundation).

This module enables tenants to view their active monthly bill details, view hostel payment QR/UPI info, submit payment UTR reference numbers with optional screenshot proof images (stored in Cloudinary folder `payment-screenshots/`), track submission status ("Payment Submitted / Verification Pending"), and view complete submission history. It also equips admins with a Payment Submissions Queue sorted newest first for reviewing submissions.

## Features Implemented

### 1. Tenant Current Bill & Hostel UPI Payment Card
- Fetches active monthly bill statement generated by PAYMENT-1 `BillingEngine` (`Rent` model).
- Displays: Billing Month, Billing Year, Room Number, Building Name, Hostel Name, Room Rent, Active Occupants, Equal Tenant Share, Due Date, Outstanding Amount, and Bill Status.
- Displays Hostel Payment Card: Hostel Name, UPI ID (`bhagirathi@upi`), Account Holder Name, Bank Name, and dynamic QR Code image (`https://api.qrserver.com/...`).
- Interactive controls: Copy UPI ID button (with copy animation & feedback), "Open UPI App" deep link (`upi://pay?...`).

### 2. Payment Submission & Validation Engine
- Validates active contract (`Contract.status == "ACTIVE"`) and non-archived tenant status (`Tenant.is_active == True`).
- Validates UTR reference code: required, 12 to 22 characters, alphanumeric format.
- System-wide duplicate UTR prevention across non-deleted payments.
- Prevents submitting for an already fully paid bill (`Rent.status == "PAID"`).
- Optional screenshot proof upload: formats PNG, JPG, JPEG, WEBP; max file size limit 10 MB.
- Stores proof image in Cloudinary folder `payment-screenshots/` and saves `proof_image_url`, `public_id`, and upload timestamp.
- Stores `Payment` record with status `"Submitted"`, `verification_status` = `PENDING`, links `PaymentAllocation` to `Rent` bill.
- Records `PaymentHistory` entry (`action` = `SUBMITTED`).
- Emits audit log events (`Payment Submitted`, `Screenshot Uploaded`, `UTR Submitted`, `Submission Updated`).

### 3. Tenant Dashboard & History Views
- **Active Submission Card**: Displays active submission badge ("Payment Submitted / Verification Pending"), UTR, amount, submission date, and screenshot preview button.
- **Payment History Page** (`/payment-history`): Displays full timeline of tenant's payment submissions with status badges (`Submitted`, `Pending Verification`, `Verified`, `Rejected`), UTR copy buttons, screenshot preview modal, and receipt printing for verified payments.

### 4. Admin Submissions Queue
- Admin Queue API (`GET /api/v1/payments/submissions`) lists payment submissions sorted newest first.
- Enriched with: Tenant Name, Room Number, Building Name, Hostel Name, Amount, UTR, Screenshot URL, Submission Time, and Status (`Submitted`, `Pending Verification`).
- Detail drawer endpoint (`GET /api/v1/payments/submissions/{id}`) for inspecting submission details.

## API Reference

### Tenant APIs

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v1/payments/current` | Get current bill details, occupancy share, active submission status, and hostel UPI QR info. |
| `GET` | `/api/v1/payments/history` | List payment submission history for the authenticated tenant. |
| `POST` | `/api/v1/payments/submit` | Submit payment UTR and optional screenshot proof image (multipart/form-data). |
| `GET` | `/api/v1/payments/status/{id}` | Get status and details of a specific payment submission. |

### Admin APIs

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v1/payments/submissions` | List payment submissions queue sorted newest first (filterable by status, hostel, building, room). |
| `GET` | `/api/v1/payments/submissions/{id}` | Get full details of a payment submission in queue. |

## Cloudinary & Database Usage

- **Cloudinary Folder**: `payment-screenshots/`
- **Supported File Formats**: PNG, JPG, JPEG, WEBP
- **Max File Size**: 10 MB
- **Database Tables**:
  - `payments`: Stores `tenant_id`, `amount`, `payment_date`, `payment_method` ("UPI"), `payment_status` (`PENDING`), `status` ("Submitted"), `verification_status` (`PENDING`), `transaction_id` (UTR), `proof_image_url`, `billing_month`, `billing_year`, `submission_date`.
  - `payment_allocations`: Links payment submission to `rent` record.
  - `payment_history`: Records `SUBMITTED` action with JSON metadata.
  - `audit_logs`: Records `Payment Submitted`, `Screenshot Uploaded`, `UTR Submitted`, `Submission Updated`.
